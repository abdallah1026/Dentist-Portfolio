# محمد إبراهيم عزيز الدين — موقع تعريفي

موقع شخصي احترافي لطبيب الأسنان **محمد إبراهيم عزيز الدين** — خريج كلية طب الفم والأسنان بجامعة أهرام كندية، دفعة ٢٠٢٣.

الموقع ثنائي اللغة (العربية افتراضيًا، والإنجليزية)، ومبني بـ HTML وCSS وJavaScript فقط — بدون أي أدوات بناء أو إطار عمل، ويمكن استضافته على أي خدمة استضافة ثابتة.

---

## 1. التشغيل محليًا

افتح مجلد المشروع في الطرفية ثم:

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

ثم افتح المتصفح على: <http://127.0.0.1:4173/>

> يمكن أيضًا فتح `index.html` مباشرةً، لكن التشغيل عبر سيرفر محلي أفضل لاختبار الصور والخطوط.

---

## 2. الملفات

```
.
├── index.html              # كل محتوى الصفحة + النصوص العربية
└── assets
    ├── css/style.css       # التصميم الكامل + الاستجابة للشاشات + الوضعين RTL/LTR
    ├── js/main.js           # بيانات التواصل + الترجمة الإنجليزية + كل التفاعلات
    └── img/                 # الصور المحسّنة (JPG + WebP)
```

الصور الأصلية (ملفات واتساب) باقية كما هي في جذر المشروع، ولا يستخدمها الموقع.

---

## 3. بيانات التواصل — **مهم قبل النشر**

كل بيانات التواصل موجودة في كائن واحد أعلى ملف `assets/js/main.js`:

```js
const SITE = {
  phone: "+201000000000",            // بصيغة دولية، بدون مسافات أو +
  phoneDisplay: "+20 100 000 0000",  // كما تظهر على الشاشة
  email: "hello@drmohamedaziz.com",
  whatsapp: "201000000000",          // بصيغة دولية بدون + وبدون أصفار بادئة
  instagram: "",                     // مثال: "https://instagram.com/your-handle"
  linkedin: ""                       // مثال: "https://linkedin.com/in/your-profile"
};
```

- القيم الحالية **بيانات مؤقتة للعرض فقط** ويجب استبدالها بالبيانات الحقيقية.
- الروابط الفارغة في `instagram` و`linkedin` تُخفى تلقائيًا، وتظهر عند إضافتها.
- رقم `whatsapp` هو المستخدم في زر «اطلب موعدًا»؛ النموذج يفتح واتساب برسالة جاهزة تحتوي الاسم والهاتف والخدمة والرسالة.
- النموذج **لا يرسل بيانات إلى أي سيرفر** ولا يخزّنها؛ لذلك لا يحتاج إلى خدمة خلفية.

## 4. تعديل النصوص

| المحتوى | المكان |
| --- | --- |
| النصوص العربية | `index.html` — داخل السمات `data-i18n` |
| النصوص الإنجليزية | `assets/js/main.js` — كائن `EN` |
| عنوان الصفحة ووصفها (SEO) | وسم `<head>` في `index.html` + مفتاحا `meta.title` و`meta.desc` في `main.js` |

النصوص العربية هي المصدر؛ يجري التقاطها عند تحميل الصفحة، لذا أي تعديل عربي يجب أن يتم في `index.html` مع مطابقة المفتاح `data-i18n` في كائن `EN`.

لإضافة نص جديد:

```html
<!-- في index.html -->
<p data-i18n="about.new">النص العربي</p>
```

```js
// في assets/js/main.js داخل EN
"about.new": "English text",
```

## 5. استبدال الصور

الملفات في `assets/img/`، وكل صورة موجودة بصيغتين (WebP + JPG احتياطية). الأسماء والمقاسات الحالية:

| الملف | المقاس | الاستخدام |
| --- | --- | --- |
| `hero-portrait` | 738×1600 | صورة البورتريه الرئيسية |
| `case-01` … `case-04` | 1280×960 / 1600×1200 | صور إكلينيكية داخل المعرض |
| `detail-instruments` | 1200×1600 | أدوات — قسم الفلسفة والمعرض |
| `detail-tray` | 1200×1600 | صينية أدوات — المعرض |

للتبديل: ضع الصورة الجديدة بنفس الاسم وبكلتا الصيغتين (JPG + WebP) مع الحفاظ على المقاس أو نسبة قريبة، ثم حدّث وسم `alt` في `index.html`. إذا اختلفت الأبعاد، عدّل `width` و`height` في وسم `<img>` لتجنّب اهتزاز التصميم أثناء التحميل.

> تنبيه: صور المعرض إكلينيكية. تأكد من موافقة المرضى على النشر قبل استخدام أي صورة تظهر فيها تفاصيل يمكن التعرف عليها، أو استبدلها بصور عامة للأدوات والعيادة.

## 6. النشر

الموقع ملفات ثابتة، فيكفي رفع `index.html` ومجلد `assets` إلى أي استضافة:

- **Netlify / Vercel / Cloudflare Pages:** اسحب المجلد كما هو.
- **GitHub Pages:** ارفع الملفات إلى المستودع وفعّل Pages من إعدادات المستودع.
- **استضافة عادية (cPanel):** ارفع الملفات إلى `public_html`.

بعد النشر:

1. حدّث روابط التواصل في `SITE`.
2. استبدل `og:image` في `<head>` برابط صورة كامل يبدأ بـ `https://` حتى تظهر معاينة صحيحة عند المشاركة.
3. أضف `og:url` بالدومين النهائي (اختياري).
4. تحقق من رقم الهاتف والبريد قبل مشاركة الموقع.

---

## 7. اللغة والوصول

- العربية هي الافتراضية (`dir="rtl"`)، وزر التبديل يحفظ الاختيار في `localStorage` تحت المفتاح `aziz-lang`.
- يمكن فتح النسخة الإنجليزية مباشرة عبر `?lang=en`.
- الموقع يدعم التنقل بلوحة المفاتيح، وتقليل الحركة (`prefers-reduced-motion`)، وأنماط الطباعة.
- نتائج Lighthouse المحلية: الوصول 100، أفضل الممارسات 100، SEO 100 (في النسختين العربية والإنجليزية).
